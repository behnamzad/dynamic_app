# Behavior event catalog

Schema version: `2`

This catalog describes the events supported by the behavior module. The core producers listed below are instrumented; event types whose
corresponding UI does not yet exist remain registered for additive future producers.

Session semantics are lifecycle-based: a fresh app launch/foreground entry starts a session, navigation across features preserves it, and
logout/background ends it. No fixed inactivity threshold changes `session_id`.

## Common envelope

| Field                                                    | Type                        | Nullable       | Meaning and analytical use                                                   |
|----------------------------------------------------------|-----------------------------|----------------|------------------------------------------------------------------------------|
| `event_id`                                               | UUID string                 | no             | Globally unique idempotency and deduplication key                            |
| `user_id`                                                | UUID string                 | no             | Authenticated user ID, or local pseudonymous ID before attribution           |
| `anonymous_id`                                           | UUID string                 | no             | Stable pseudonymous installation identity retained through login attribution |
| `session_id`                                             | UUID string                 | no             | Session grouping and ordered sequence construction                           |
| `event_type`                                             | enum wire name              | no             | Stable event semantics                                                       |
| `event_timestamp`                                        | UTC timestamp               | no             | Interaction time used for sequences, cutoffs, and labels                     |
| `client_generated_at`                                    | UTC timestamp               | no             | Client creation time and timing diagnostics                                  |
| `app_version`                                            | string                      | no             | App compatibility and producer-version diagnostics                           |
| `schema_version`                                         | integer                     | no             | Historical decoding and feature compatibility                                |
| `is_authenticated`                                       | boolean                     | no             | Authentication state at interaction time                                     |
| `product_id`, `category_id`, `brand_id`                  | string                      | event-specific | Stable joins, aggregates, sequences, and attribution                         |
| product/category/brand names and hierarchy               | snapshot                    | event-specific | Interaction-time, self-describing context                                    |
| `source_screen`, `destination_screen`, `referrer_screen` | string                      | yes            | Navigation and attribution context                                           |
| `duration_ms`                                            | non-negative integer        | yes            | Dwell and abandonment features                                               |
| `position`                                               | non-negative integer        | yes            | Rank/list-position exposure bias                                             |
| `event_status`                                           | string                      | yes            | Outcome or state when applicable                                             |
| `payload`                                                | typed versioned JSON object | no             | Event-family-specific context                                                |
| `context`                                                | typed JSON object           | no             | Platform, locale, online state, timezone, experiment, and cohort             |

Price, discount, cart monetary value, stock, availability, credentials, tokens, payment secrets, and free-text review/comment bodies are
forbidden.

## Typed payload ownership

- `NavigationBehaviorPayload`: route/tab, scroll/list position, and visible item IDs.
- `ProductBehaviorPayload`: source/rank/slot, impression linkage, image/gallery behavior, scroll, review count/open trigger, quantity and
  selected variant.
- `CategoryBrandBehaviorPayload`: source/rank/slot, filter/sort, transitions and visible product IDs.
- `SearchBehaviorPayload`: original/normalized query, result count/order/snapshots, selected result, refinement, filters/sort and elapsed
  attribution time.
- `CartBehaviorPayload`: quantities, cart product IDs/snapshots, product count, time from first view and recommendation attribution.
- `CheckoutBehaviorPayload`: step/outcome/failure code, purchased product IDs/snapshots/quantities and time-to-conversion.
- `RecommendationBehaviorPayload`: request ID, candidate/displayed IDs and snapshots, selected product, rank/slot, strategy, model version,
  next action and confidence.
- `FeedbackBehaviorPayload`: target type/ID, rating or enumerated feedback value, and buyer state; never review text.
- `LifecycleBehaviorPayload`: lifecycle reason, session event count and duration.

`BehaviorEventCatalog.validateDraft` enforces required product/category/brand IDs and descriptive snapshots and recursively rejects
prohibited extensible metadata keys before durable storage.

All producer calls use `BehaviorLogger.recordNonBlocking`. They enqueue locally through the existing repository and never wait for Supabase
or trigger sync from the UI interaction.

Ranks and image indexes are zero-based. Search normalization currently trims the query and applies lowercase without collecting additional
sensitive text. `product_reviews_view` is recorded immediately when the user deliberately opens a full comment; the matching
`product_reviews_view_end` carries `content_type=reviews` and `duration_ms` so repeated opens and reading dwell remain separately derivable.
Product-detail gallery autoplay is disabled so `product_image_swipe` represents a manual action. Unnamed modal routes such as review bottom
sheets do not emit false screen exit/enter pairs.

Schema version 2 corrects producer semantics without rewriting history: it separates review-area end from `product_view_end`, stops
automatic carousel transitions from being recorded as user swipes, ignores unnamed modal routes for screen lifecycle, and adds thresholded
product scroll depth. Feature extraction must retain version 1 rows but exclude or explicitly flag its known autoplay-generated image-swipe
pattern.
